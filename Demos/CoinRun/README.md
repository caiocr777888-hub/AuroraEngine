# Coin Run

Abra project.aurora no AuroraEngine.exe, clique Play e depois Jogar. Use WASD ou setas para mover o cubo azul. Colete as cinco moedas douradas para vencer. A pontuação aparece no jogo. R ou o botão Reiniciar restaura a partida. Stop retorna à cena de edição.

Os scripts ficam em Scripts. Os controles são configurados em input.json. A demo usa câmera de jogo, HUD, troca de cenas, colisores e gatilhos da engine.

Para jogar fora do editor, use File → Export Windows game e escolha uma pasta vazia fora do projeto. Abra Play.exe na pasta exportada. Mantenha a pasta Game junto do executável. O destino precisa de .NET Framework com WPF.
